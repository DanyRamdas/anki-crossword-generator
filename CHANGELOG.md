# Changelog

## 0.6.4

- Improved printable puzzle sizing, clue typography, spacing, grid boundaries, and clue-number legibility.

## 0.6.3

- Default export filenames now include today's date.
- Marking a puzzle solved now labels its history entry as solved.
- Clarified card-state choices and hid preview answers by default.
- Updated the configuration screenshot.

## 0.6.2

- Made the JMdict backfill use the currently selected Native answer field instead of assuming `englishWord`.

## 0.6.1

- Removed Fill-in-the-gap clues from the interface and documentation for now.

## 0.6.0

- Added optional JMdict-backed `englishWord` field backfill for Japanese → Native crosswords.
- Added the live AnkiWeb listing and refreshed the configuration screenshot.

## 0.5.0

- Added PNG and SVG export from PDF preview.
- Added printing through the system print dialog.
- Added profile-local puzzle history with reopen and remove actions.
- Clarified the two modes as Native → Japanese and Japanese → Native.
- Added selected-clue highlighting and improved puzzle-window controls.

## 0.4.0

- Added printable A4 puzzle and answer-key PDF export.
- Added PDF preview and interactive crossword solving.
